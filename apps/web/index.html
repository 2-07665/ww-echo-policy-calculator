使用说明

强化策略

  1. 选择角色预设和变体，填写目标总分；按需调整词条权重和资源相对价值。
  2. 填入当前声骸已揭示的词条及数值；新胚子留空。点击「求解策略」。
  3. 每次强化后更新词条，建议会立即刷新。建议放弃时，换一个胚子并点击「清空」；建议保留时，留下当前声骸。
  4. 修改评分、目标或资源相对价值后，重新点击「求解策略」。

重抽策略

  1. 选择角色预设和变体，填写目标总分，并填入当前声骸完整的五条副词条及数值。点击「求解策略」。
  2. 按建议锁定词条，在游戏中使用频整器重抽，再将完整的五条结果填入重抽候选。候选比较会自动更新。
  3. 决定接受时，点击「接受候选并继续重抽」；已达标时按钮显示「接受候选」。候选会成为当前声骸，下一步建议自动更新。
  4. 决定保留原结果时，点击「清空候选」，继续按当前声骸的建议重抽。达标后停止重抽。
  5. 修改当前声骸或候选会自动更新建议；修改评分或目标后，重新点击「求解策略」。

联合策略

  1. 选择角色预设和变体，填写目标总分，设置资源相对价值，包括频整器。
  2. 填入当前声骸已揭示的词条及数值；新胚子留空。点击「求解策略」。
  3. 按建议继续强化，每次强化后更新词条。建议放弃时，换一个胚子并点击「清空」；建议保留时，留下当前声骸。
  4. 建议重抽时，点击「转到重抽策略」。当前声骸、评分和目标会自动带入，接着按重抽模式的步骤操作。
  5. 修改评分、目标或资源相对价值后，重新点击「求解策略」。
