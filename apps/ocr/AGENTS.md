# OCR 子系统

- 原生 Windows x64 CPU 子进程源码在 `native/`，不向游戏注入，不读取游戏内存，不发送游戏输入。
- 首版仅处理简体中文、16:9 客户区的装备页（右侧）和强化页（左侧），每页仅识别最多 5 条副词条；主词条、强化结果弹窗和动画页不属于识别范围。
- 客户区坐标以 1920×1080 为基准。窗口截图中的标题栏／边框必须扣除，不能将截图总尺寸当作游戏尺寸；真实捕获须依据窗口几何裁剪，不猜测边框。
- 使用 PP-OCRv6 small 识别模型、匹配字典及 ONNX Runtime CPU。固定行布局不使用检测模型、方向分类或赛马娘增强；不得无意引入 Python、OpenCV、CUDA、OpenVINO 到发布目录。
- `runtime/`、`.deps/` 和仓库根目录 `captures/` 是本地生成资源，禁止提交模型、SDK 或含用户 UID 的原图。来源、摘要和固定版本沿准备脚本及 `native/SOURCES.md` 维护。
- 识别结果只能在页面锚点、完整候选词条、合法数值及连续两次一致均通过后发送。失效、最小化、窗口／尺寸／页面变化须清除待确认状态，不发送部分识别结果。
- 保留 `EchoOCRTask.py` 的外部 ok-ww 集成和 UDP 9999 协议；内置识别和外部识别由用户二选一。
- 验证区分固定截图、受控窗口 WGC／UDP 和真实游戏。前两类成功不能写成游戏内后台识别已验收。
